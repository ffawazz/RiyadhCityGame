YOUR OWN MUSIC
==============
Put a song here and that sister will play it instead of the built-in track:

    daniah.mp3   (or daniah.ogg)
    sarah.mp3    (or sarah.ogg)
    lamia.mp3    (or lamia.ogg)

For example, copy your own copy of a song to  music\lamia.mp3  and pick Lamia.
The song loops. If the file is missing the game uses its built-in synthesised music.
The built game (.exe) looks for a "music" folder next to the .exe as well.
